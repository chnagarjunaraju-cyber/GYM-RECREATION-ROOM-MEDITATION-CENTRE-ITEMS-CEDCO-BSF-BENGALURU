# CEDCO BSF Bengaluru Gym Equipment Inventory — V66

GitHub Pages/browser backup fix.

## Backup JSON
The Settings → Backup JSON button now creates and downloads a complete JSON backup in the browser, including product records and transaction history. It also shows a confirmation message and falls back cleanly when the desktop bridge is unavailable.

## Import JSON
Import accepts the generated backup format and older array-style backups, then refreshes the application immediately.

Open `index.html` from the repository root for GitHub Pages.
