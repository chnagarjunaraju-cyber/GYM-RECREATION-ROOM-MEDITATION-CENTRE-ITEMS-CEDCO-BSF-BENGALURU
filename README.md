# CEDCO BSF Bengaluru Gym Equipment Inventory

GitHub Pages package for the **CEDCO BSF BENGALURU GYM EQPTS INVENTORY** application.

## Publish with GitHub Pages

1. Upload the **contents of this folder** to the root of your GitHub repository.
2. Make sure `index.html` is in the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.

The bundled application assets are included locally.

## Important

GitHub Pages hosts the web application files. Browser localStorage/IndexedDB data remains local to each browser/device and is not a shared server database.
